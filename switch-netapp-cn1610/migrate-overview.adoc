= 2ノードスイッチドクラスタの移行オプション（NetApp CN1610クラスタスイッチ使用）
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
2ノードのスイッチレスクラスタを使用している場合、NetApp CN1610クラスタネットワークスイッチを含む2ノードのスイッチ付きクラスタに、中断することなく移行できます。使用する手順は、各コントローラに専用のクラスタネットワークポートが2つあるか、各コントローラにクラスタポートが1つしかないかによって異なります。

ほとんどのシステムでは、各コントローラに2つの専用クラスタネットワーク ポートが必要です。

FAS22xxノードでは、各コントローラに1つのクラスタポートを使用できます。

移行オプションは2つあります：

* link:migrate-switched-netapp-cn1610.html["スイッチレスクラスタからスイッチ使用の NetApp CN1610 クラスタ環境への移行"]
* link:migrate-fas22xx-systems.html["スイッチレスクラスタ（単一のクラスタネットワーク接続を持つFAS22xxシステム）からの移行"]
