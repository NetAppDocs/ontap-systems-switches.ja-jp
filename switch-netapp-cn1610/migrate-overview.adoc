= NetApp CN1610クラスタスイッチの移行オプションを確認する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
2ノードのスイッチレスクラスタからNetApp CN1610クラスタスイッチを使用したスイッチドクラスタへの移行オプションを確認します。手順は、各コントローラに専用のクラスタネットワークポートが2つあるか、それともクラスタポートが1つしかないかによって異なります。

ほとんどのシステムでは、各コントローラに2つの専用クラスタネットワーク ポートが必要です。

FAS22xxノードでは、各コントローラに1つのクラスタポートを使用できます。

移行オプションは2つあります：

* link:migrate-switched-netapp-cn1610.html["スイッチレスクラスタからスイッチ使用の NetApp CN1610 クラスタ環境への移行"]
* link:migrate-fas22xx-systems.html["スイッチレスクラスタ（単一のクラスタネットワーク接続を持つFAS22xxシステム）からの移行"]
