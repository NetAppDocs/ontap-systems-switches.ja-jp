= NetApp CN1610 クラスタスイッチについて
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp CN1610は、16個の10ギガビットSFP+ポートを備えた、高帯域幅のマネージド型レイヤ2クラスタスイッチです。このページでは、スイッチの機能とONTAPクラスタネットワークにおける役割について説明します。

このスイッチには冗長電源とファンユニットが搭載されており、高可用性を実現するためにホットスワップに対応しています。この1Uスイッチは、標準的な19インチのNetApp 42Uシステムキャビネット、またはサードパーティ製キャビネットに取り付けることができます。

このスイッチは、コンソールポートを介したローカル管理、またはネットワーク接続を介したTelnetやSSHによるリモート管理をサポートしています。CN1610には、帯域外スイッチ管理用の専用1ギガビットイーサネットRJ45管理ポートが搭載されています。スイッチの管理は、コマンドラインインターフェース（CLI）にコマンドを入力するか、SNMPベースのネットワーク管理システム（NMS）を使用することで行えます。
