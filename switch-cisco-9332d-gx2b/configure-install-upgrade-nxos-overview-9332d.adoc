= Cisco Nexus 9332D-GX2B スイッチへの NX-OS のインストールまたはアップグレードについて
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cisco Nexus 9332D-GX2B スイッチに NX-OS をインストールまたはアップグレードします（AFX 1K および AFX 2K システム向け）。


NOTE: NX-OSのインストールまたはアップグレードは、RCFのインストールまたはアップグレードとは独立しています。NX-OSとRCFの両方をインストールまたはアップグレードする場合は、先にNX-OSをインストールまたはアップグレードすることをお勧めします。

* link:configure-install-nxos-9332d.html["NX-OSをインストールします"]
+
NX-OSは、AFX 1KまたはAFX 2Kシステムの新規インストール、スイッチの交換、またはスイッチを工場出荷時のデフォルト設定にリセットする際に、スイッチにインストールします。

* link:configure-upgrade-nxos-9332d.html["NX-OSをアップグレードする"]
+
新しいハードウェアまたは新しい ONTAP バージョンをサポートするために、AFX 1K または AFX 2K システムのスイッチの NX-OS をアップグレードします。
