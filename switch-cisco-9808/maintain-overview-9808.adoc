= Cisco Nexus 9808スイッチのメンテナンスオプションについて
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cisco Nexus 9808 スイッチで利用可能なメンテナンス タスクを確認してください。これには、故障したスイッチ コンポーネント（FRU）の交換、故障したスイッチの交換、およびスイッチを工場出荷時のデフォルト設定にリセットする作業が含まれます。

スイッチに対して、以下のメンテナンス作業を実行できます。

* link:maintain-replace-frus-9808.html["FRUを交換する"]
* link:maintain-reset-switch-9808.html["スイッチを工場出荷時の設定にリセットする"]
