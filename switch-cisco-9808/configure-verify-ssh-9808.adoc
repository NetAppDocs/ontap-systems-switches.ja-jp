= Cisco Nexus 9808 スイッチでログ収集のための SSH を確認する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cisco Nexus 9808 スイッチで SSH が有効になっていることを確認し、イーサネット スイッチ ヘルス モニター（CSHM）機能とログ収集機能をサポートします。

.開始する前に
スイッチにシリアル コンソールを使用して接続する必要があります。

.手順
. SSH が有効になっていることを確認します。
+
[listing, subs="+quotes"]
----
(switch) *show ssh server*
ssh version 2 is enabled
----
. SSH キーが有効になっていることを確認します。
+
`show ssh key`

+
