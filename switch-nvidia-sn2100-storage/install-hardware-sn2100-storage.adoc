= NVIDIA SN2100 ストレージスイッチのハードウェアをインストールする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NVIDIA のドキュメントに従って、NVIDIA SN2100 ストレージスイッチのハードウェアをインストールしてください。ハードウェアのインストールは、スイッチをストレージ ネットワーク運用向けに設定する前の最初の手順です。

SN2100 スイッチをセットアップおよび構成するには、次の手順に従います。詳細な手順については、NVIDIA のドキュメントを参照してください。

.手順
. レビューlink:configure-reqs-sn2100-storage.html["構成要件"]。
. link:https://networking-docs.nvidia.com/sn2000hw/latest/installation["NVIDIAスイッチ インストール ガイド"^]の手順に従ってください。


.次の手順
ハードウェアをインストールしたら、link:cabling-considerations-sn2100-storage.html["ケーブル配線と構成を確認する"]要件。
