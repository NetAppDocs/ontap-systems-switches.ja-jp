= Cisco Nexus 3132Q-V ケーブル配線ワークシートに記入する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cisco Nexus 3132Q-V クラスタスイッチのケーブル配線ワークシートに必要事項を記入し、ポート接続とサポートされているプラットフォーム構成を記録してください。

サンプル配線ワークシートには、スイッチからコントローラへの推奨ポート割り当ての例が示されています。空白のワークシートには、クラスターの設定に使用できるテンプレートが用意されています。

各スイッチは、単一の40GbEポート、または4 x 10GbEポートとして構成できます。
