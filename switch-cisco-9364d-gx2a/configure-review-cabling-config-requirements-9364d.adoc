[[hard-code-the-speed-on-breakout-ports]]
== ブレークアウトポートの速度をハードコーディングする

100GbE 用のスイッチブレークアウト (4x100GbE) ポートはハードコーディングする必要があります。速度をハードコーディングしない場合、ポートは起動せず、エラー無効状態になります。

例えば、ブレークアウトポート1～13に100GbEをハードコーディングするには、設定モードで以下の操作を行います。この例では、最初のスイッチ（cs1）にコマンドが適用されている様子を示しています。2つ目のスイッチに対しても、これらのコマンドを繰り返します。

[listing, subs="+quotes"]
----
(cs1)(config)# *interface e1/1/1-4, e1/2/1-4, e1/3/1-4, e1/4/1-4, e1/5/1-4, e1/6/1-4, e1/7/1-4, e1/8/1-4, e1/9/1-4, e1/10/1-4, e1/11/1-4, e1/12/1-4, e1/13/1-4*
(cs1)(config-if)# *speed 100000*
(cs1)(config-if)# *no negotiate auto*
(cs1)(config-if)# *exit*
(cs1)(config)# *exit*
(cs1)# *copy running-config startup-config*
----
