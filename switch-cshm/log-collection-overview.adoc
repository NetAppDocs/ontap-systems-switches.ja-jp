= ログ収集の概要
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ログ収集を設定すると、 AutoSupportによって収集される定期的なデータの 1 時間ごとの収集を有効にし、詳細なサポート ログを要求することができます。

ログ収集は、スイッチのログと診断データを自動的に収集することで、ネットワーク スイッチの問題のトラブルシューティングに役立ちます。スケジュールに基づいて定期的にデータを収集するには AutoSupport を使用するか、特定の問題のトラブルシューティングに詳細なログが必要な場合はオンデマンド収集をトリガーします。収集されたログは、スイッチの状態、設定変更、およびネットワーク イベントに関する情報を提供します。

詳細については、link:config-log-collection.html["ログ収集を構成する"]を参照してください。
