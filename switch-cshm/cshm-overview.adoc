= イーサネット スイッチの健全性モニター
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
イーサネットスイッチヘルスモニター（CSHM）は、ネットワークスイッチの動作状態を正常に保ち、デバッグ目的でスイッチログを収集する役割を担います。

CSHM はクラスタおよびストレージ ネットワーク スイッチを監視し、ネットワーク インフラの信頼性を維持します。ヘルス モニターは、スイッチの問題を自動的に検出し、トラブルシューティングのためのログを収集し、ネットワークの問題が発生した際にアラートを発信します。CSHM は複数のスイッチ ベンダーとモデルをサポートしており、ストレージ環境に影響が出る前にネットワーク接続の問題を特定して解決するのに役立ちます。
