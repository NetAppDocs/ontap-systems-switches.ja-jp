= 設定の概要
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
イーサネットスイッチヘルスモニター（CSHM）は、ネットワークスイッチの動作状態を正常に保ち、デバッグ目的でスイッチログを収集する役割を担います。

CSHMを使用してネットワーク スイッチを監視するには、まずログ収集を設定し、必要に応じてセキュリティ強化のためにSNMPv3を設定する必要があります。CSHMがスイッチログと診断データを収集するには、ログ収集が必要です。SNMPv3は、ONTAPとスイッチ間のセキュアな通信を提供します。

* link:config-log-collection.html["ログ収集を構成する"]
* link:config-snmpv3.html["SNMPv3 を構成する (オプション)"]
